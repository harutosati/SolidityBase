SolidityBase provides a scalable, modular framework for efficient smart contract execution and gas-optimized module deployment.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/SolidityBase.git`
2. `cd SolidityBase`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure SolidityBase, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
